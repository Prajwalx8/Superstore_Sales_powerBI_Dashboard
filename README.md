🛒 Superstore Sales Dashboard (Power BI)

A fully interactive Power BI dashboard built using the Superstore dataset to analyze sales, profit, customer segments, and delivery performance.

📌 Project Overview

This dashboard provides an end-to-end analysis of retail performance, including:

1. Total Sales, Quantity, Profit, and Average Delivery Time
2. Monthly Sales & Profit YoY trends
3. Sales by Region, Category, Segment, and Subcategory
4. Top 5 States by Sales
5. Payment Mode and Ship Mode distribution

📂 Key Features

1. KPI cards for Sales, Quantity, Profit, and Avg Delivery
2. Interactive Region and Ship Mode filters
3. Donut charts for Region, Payment Mode, and Segment insights
4. Time-series line charts for YoY trends
5. Category & Subcategory breakdowns
6. Treemap for Top 5 States

🛠 Tools & Technologies

1. Power BI
2. Superstore dataset (CSV)
3. Power Query for data cleaning
4. Data modeling inside Power BI
