🛒 Superstore Sales Dashboard (Power BI)

A fully interactive Power BI dashboard built using the Superstore dataset to analyze sales, profit, customer segments, and delivery performance.

📌 Project Overview

This dashboard provides an end-to-end analysis of retail performance, including:

Total Sales, Quantity, Profit, and Average Delivery Time
Monthly Sales & Profit YoY trends
Sales by Region, Category, Segment, and Subcategory
Top 5 States by Sales
Payment Mode and Ship Mode distribution

📂 Key Features

KPI cards for Sales, Quantity, Profit, and Avg Delivery
Interactive Region and Ship Mode filters
Donut charts for Region, Payment Mode, and Segment insights
Time-series line charts for YoY trends
Category & Subcategory breakdowns
Treemap for Top 5 States

🛠 Tools & Technologies

Power BI
Superstore dataset (CSV)
Power Query for data cleaning
Data modeling inside Power BI
